# AGENTS.md

## Cursor Cloud specific instructions

### Architecture

Single Next.js 14 (App Router) application with one API route (`POST /api/chat`) that proxies to OpenAI GPT-3.5-turbo with SSE streaming. No database — chat history stored in browser localStorage. See `README.md` for full stack details.

### Key development commands

See `package.json` scripts; the important ones:

- **Dev server**: `pnpm dev` (runs on http://localhost:3000)
- **Build**: `pnpm build`
- **Lint**: `pnpm lint` (ESLint with import sorting)
- **Type check**: `pnpm lint:type-check` (pre-existing type error in `MarkdownRenderer.tsx` from `react-syntax-highlighter` types mismatch — this is expected)
- **Tests**: `pnpm test:all` (Jest configured but no test files exist yet; use `--passWithNoTests` to avoid exit code 1)

### Non-obvious gotchas

- **`@tencent/*` packages**: These are private Tencent packages not on public npm. `.pnpmfile.cjs` strips them during `pnpm install`. They are NOT imported anywhere in source code, only listed in `package.json`.
- **`postinstall` runs `next build`**: The `package.json` `postinstall` script runs a full build. Use `pnpm install --ignore-scripts` to install dependencies without triggering a build, then build separately if needed.
- **`OPENAI_API_KEY` required for chat**: Without this env var in `.env.local`, the `/api/chat` endpoint returns HTTP 500. The UI still loads and is functional for development, but the AI chat feature won't work.
- **ESLint config**: The original `@tencent/eslint-config-tencent` was replaced with `next/core-web-vitals` + `plugin:@typescript-eslint/recommended` since the Tencent config is not publicly available.
- **Generated PWA files**: `public/sw.js` and `public/workbox-*.js` are generated by `next-pwa` during build. They are excluded from linting via `.eslintignore`.
